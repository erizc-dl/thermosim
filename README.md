# Thermosim - thermostat simulation program

This is a simulation project in progress that simulates the indoor/outdoor temperature and controls the thermostat to perform certain actions.

# Goal

It should eventually include

- an AC
- heater
- temperature sensor
- indoor/outdoor temperature
- persistent memory
- error handling

# Execution

To execute the program, download thermosim.py and run
```
python3 thermosim.py
```
